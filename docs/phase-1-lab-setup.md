# Phase 1 - Lab Setup

This document outlines the initial setup steps for the Home SOC Lab using Splunk.

## Objectives

- Deploy a Splunk instance for log collection and analysis
- Configure data inputs for common sources
- Create a basic home lab environment for security monitoring

## Suggested workflow

1. Provision or reuse a VM for the lab
2. Install Splunk Enterprise or Splunk Free
3. Configure indexes and data inputs
4. Ingest logs from Windows, Linux, and network devices
5. Build dashboards and alerts for basic detections

## Notes

This is a placeholder setup guide and can be expanded as the lab grows.
