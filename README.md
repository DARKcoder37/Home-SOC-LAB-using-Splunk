# Home SOC LAB using Splunk

This repository contains resources, docs, and sample artifacts for a home SOC lab built around Splunk.

## Structure

- `docs/` – lab setup and walkthroughs
- `screenshots/` – screenshots captured during exercises
- `detections/` – detection rules and hunting content
- `incident-reports/` – sample incident reporting templates and examples

See `docs/phase-1-lab-setup.md` for the initial environment setup.
